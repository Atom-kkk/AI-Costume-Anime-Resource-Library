## 功能

- **分类筛选**：顶部标签页切换八大分类，实时统计数量。
- **中英双语搜索**：支持按 ID（如 `SPR-0001`）、中文关键词（如 `牛仔`、`蕾丝`、`白`）、英文关键词（如 `denim`、`lace`）检索。
- **大图浏览**：点击卡片查看大图，支持 `←` `→` 切换、`Esc` 关闭。
- **本地图片**：全部展示图与缩略图已下载，断网也能看。
- **响应式**：桌面多列网格，移动端自动收窄为两列。

### 字段说明

| 字段 | 说明 |
| --- | --- |
| `id` | 服装编号，前缀对应分类：`SPR` 春 / `SUM` 夏 / `AUT` 秋 / `WIN` 冬 / `LNG` 内衣 / `PTY` 派对 / `SWM` 泳装 / `SXY` 性感 |
| `category` | 中文分类名 |
| `categoryJa` | 原站日文分类名（便于对照） |
| `keywords` | 中文关键词 |
| `keywordsEn` | 原站英文关键词原文 |
| `thumb` | 缩略图相对路径（本地） |
| `image` | 展示图相对路径（本地） |
| `original` | 原尺寸 PNG 地址（未收录，指向原站） |
